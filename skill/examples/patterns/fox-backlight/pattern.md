# fox-backlight

来源：C9 `svp-cold-fox` / `build_fox.py`。

## 可借

- 远景针叶林低对比，先压成剪影群
- 背雾 / 地雾分两层，拉开树干前后
- 狐狸主体先 under，再 coat，再 detail
- `fox_rim` 用 screen，只擦受光边，不铺满
- 23 层 / 47,032 笔，主体只占小面积

## 不要照搬

- 不要把所有树都画成同一轮廓
- 不要用 fox_rim 描一整圈
- 地面不要先画细节再压雾

## 已知副作用

- 逆光过强会吃掉狐狸固有色
- 雾层太多会让中景发灰
- 47k 笔里大量是背景，主体细化不够会空

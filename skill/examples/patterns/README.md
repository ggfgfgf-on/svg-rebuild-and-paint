# Pattern examples

不是完整 driver，是技法切片：crop / snippet / metrics / known issues。

| pattern | 借什么 |
|---|---|
| sky-soft | 低对比渐变、软云带、受光云底 |
| tower-brick | 不透明塔身、分面、竖向刀笔、窗洞独立 |
| impasto-density | 三遍递减、dry/bristle 方向笔、细节预算集中 |
| sunset-soft | 不透明天空渐变、软云带、窄反光柱 |
| fox-backlight | 逆光林层、雾分层、主体边缘光 |
| betta-fin | 鳍膜分层、放射鳍条、尾缘提亮 |
| heron-marsh | 主体五层、长颈收尖、压缩倒影、芦苇前后景 |

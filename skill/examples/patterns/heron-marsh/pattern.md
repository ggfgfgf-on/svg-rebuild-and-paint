# heron-marsh

来源：B8 `svp-cold-heron-boat2` / `build_heron.py`。

## 可借

- 主体按 silhouette → form → feathers → detail → rim 分五层
- 长颈用收尖曲线，不要等宽描边
- 倒影是压缩的横向碎笔，不是镜像复制
- 芦苇分 far / mid / front，前层稀疏且更高
- 20 层 / 22,266 笔，主体边缘比背景实

## 不要照搬

- 不要把这只苍鹭当解剖参考
- 不要让倒影比主体更实
- 不要用同一套芦苇笔刷铺满前景

## 已知副作用

- 头颈比例容易风格化过头
- 倒影过密会脏水
- 芦苇齐高会像栅栏

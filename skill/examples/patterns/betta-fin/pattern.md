# betta-fin

来源：C7 `betta_v2.png` / `build_betta.py`。

## 可借

- 鱼鳍拆成 dorsal / anal / tail / tail_ray / tail_edge，不在一层画完
- 鳍膜先铺低透明大形，再压放射状鳍条
- 尾缘单独提亮，避免整片红糊成一块
- 水体有 rays / caustic / particles，但都是 screen 或低透明
- 29 层 / 28,799 笔，主体边缘比背景实

## 不要照搬

- 不要把所有鳍画成同一红色
- 不要用等宽线条画鳍条
- 不要给水体加满 caustic

## 已知副作用

- 鳍条过密会像梳子
- 尾缘过亮会割裂鱼体
- 背景粒子太多会抢主体
